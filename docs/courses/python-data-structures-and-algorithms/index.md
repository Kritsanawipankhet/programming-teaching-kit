# Python Data Structures and Algorithms

## Course Description

**Python Data Structures and Algorithms** is a beginner-friendly course for learners who already know Python fundamentals and want to solve problems more efficiently.

In this course, you will learn how to choose the right data structure, understand algorithm speed, and write clear Python solutions for common programming problems.

## Prerequisites

Before starting this course, you should be comfortable with:

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists, tuples, sets, and dictionaries

## Course Content

Throughout this course, you will learn:

### Algorithm Thinking

Learn how to describe and compare solutions.

- What an algorithm is
- Input, output, and steps
- Time complexity
- Space complexity
- Big O notation

### Core Data Structures

Learn how data can be organized for different types of problems.

- Arrays and Python lists
- Stacks
- Queues
- Hash tables with dictionaries and sets
- Classes for node-based data structures
- Linked lists
- Heaps
- Binary search trees

### Common Algorithms

Learn practical algorithms used in many coding problems.

- Recursion
- Bubble sort
- Selection sort
- Insertion sort
- Using Python built-in sorting

## Final Project Idea

After completing the lessons, build a small **student ranking system**.

The program should be able to:

- Store student names and scores
- Search for a student by name
- Sort students by score
- Show the top three students
- Explain which data structures and algorithms were used
