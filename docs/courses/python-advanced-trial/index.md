# Python Advanced Trial Class

## Course Description

**Python Advanced Trial Class** is a short demo course for learners who already know Python basics and want to write cleaner, more expressive code.

The main topic is **list comprehension**. If time allows, the class can continue into **lambda**, **map**, and **filter** as a quick preview of functional-style Python.

This course is designed for a **20-minute trial lesson**.

## Target Learners

This class works best for learners who can already:

- Create and use variables
- Use lists
- Write `for` loops
- Use `if` statements
- Define simple functions

## Learning Goals

By the end of the demo, learners should be able to:

- Explain why list comprehension is useful.
- Convert a simple `for` loop into list comprehension.
- Add conditions inside list comprehension.
- Read list comprehension without feeling lost.
- Understand when `lambda`, `map`, and `filter` may be useful.

## 20-Minute Demo Flow

| Time | Activity |
|------|----------|
| 0-3 min | Review normal loops with a small list problem |
| 3-8 min | Convert a loop into list comprehension |
| 8-13 min | Add filtering with `if` |
| 13-17 min | Mini challenge: transform and filter data |
| 17-20 min | Optional preview: `lambda`, `map`, and `filter` |

## Course Content

### Main Topic

Learn how to create new lists from existing lists in one readable line.

- Basic list comprehension syntax
- Transforming values
- Filtering values
- Comparing loop style and comprehension style
- Common mistakes

### Optional Preview

Introduce compact functions and data-processing helpers.

- `lambda`
- `map()`
- `filter()`
- When list comprehension is easier to read
