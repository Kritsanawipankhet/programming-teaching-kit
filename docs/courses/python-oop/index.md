# Python Object-Oriented Programming

## Course Description

**Python Object-Oriented Programming** is a beginner-friendly course for learners who already know Python fundamentals and want to organize programs using classes and objects.

In this course, you will learn how to model real-world ideas with code, create reusable components, and write programs that are easier to maintain as they grow.

## Prerequisites

Before starting this course, you should be comfortable with:

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists and dictionaries

## Course Content

Throughout this course, you will learn:

### OOP Foundations

Learn the core ideas behind object-oriented programming.

- Classes
- Objects
- Attributes
- Methods
- The `self` parameter

### Building Classes

Learn how to create classes that store data and behavior together.

- Constructors with `__init__`
- Instance attributes
- Instance methods
- Returning values from methods

### Writing Better Object-Oriented Code

Learn techniques that make classes safer and more reusable.

- Encapsulation
- Private attributes by convention
- Getter and setter methods
- Input validation

### Reusing and Combining Classes

Learn how classes can work together in larger programs.

- Inheritance
- Method overriding
- Polymorphism
- Composition

## Final Project Idea

After completing the lessons, build a small **student management system** using classes.

The program should be able to:

- Create student objects
- Store names and scores
- Calculate average scores
- Display student reports
- Group students inside a classroom object
