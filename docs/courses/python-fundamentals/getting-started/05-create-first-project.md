# Create Your First Project

Let's create your first Python project.

## Step 1

Create a folder named:

```text
hello-python
```

## Step 2

Open VS Code.

Choose:

```text
File → Open Folder
```

Open:

```text
hello-python
```

## Step 3

Create a new file.

Name it:

```text
main.py
```

Your project should look like this.

```text
hello-python/
└── main.py
```

## Summary

You have created your first Python project.
