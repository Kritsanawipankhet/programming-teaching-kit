# Install VS Code

Visual Studio Code (VS Code) is a free and lightweight code editor.

## Step 1

Download VS Code from:

https://code.visualstudio.com/

## Step 2

Run the installer.

Use the default installation options.

## Step 3

Launch Visual Studio Code.

You should see the Welcome page.

## Why VS Code?

VS Code provides:

- Syntax highlighting
- Auto completion
- Integrated terminal
- Debugging
- Extensions

## Summary

VS Code is ready for Python development.
