# Verify Installation

Let's make sure Python was installed correctly.

## Open a Terminal

Windows

```text
Command Prompt
```

or

```text
PowerShell
```

## Check Python Version

```bash
python --version
```

or

```bash
python3 --version
```

Example output

```text
Python 3.13.6
```

If you see a version number, Python is installed successfully.

## Summary

Your Python installation has been verified.
