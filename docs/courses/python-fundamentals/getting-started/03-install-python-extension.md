# Install Python Extension

The Python Extension adds Python support to Visual Studio Code.

## Step 1

Open VS Code.

## Step 2

Open the Extensions panel.

Shortcut:

```text
Ctrl + Shift + X
```

## Step 3

Search for:

```text
Python
```

Install the extension published by **Microsoft**.

## Features

The extension provides:

- IntelliSense
- Syntax highlighting
- Code formatting
- Debugging
- Python interpreter selection

## Summary

Your editor is now ready for Python development.
