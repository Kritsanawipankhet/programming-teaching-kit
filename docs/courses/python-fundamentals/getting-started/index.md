# Getting Started

Before we begin learning Python, let's make sure your computer is ready.

In this section, you will install the required software and verify that everything is working correctly.


## Software Requirements

This course uses the following software:

| Software | Purpose | Download |
|----------|---------|----------|
| Python 3.x+ | Programming language | 🔗 [Python](https://www.python.org/downloads/){ target="_blank" } |
| Visual Studio Code | Code editor | 🔗 [VS Code](https://code.visualstudio.com/Download){ target="_blank" } |
| Python Extension | Python support for VS Code | 🔗 [Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python){ target="_blank" } |


## Setup Guide

Complete the following steps before moving to the lessons.

1. Install Python
2. Install Visual Studio Code
3. Install the Python Extension
4. Verify your Python installation
5. Create your first Python project
6. Run your first Python program


## Learning Tips

To get the most out of this course:

- Type every example yourself instead of copying.
- Complete every exercise.
- Experiment with the code.
- Don't worry about making mistakes.
- Practice regularly.

Programming is a practical skill. The more you practice, the more confident you will become.
