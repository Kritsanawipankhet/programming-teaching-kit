# Run Your First Program

Open `main.py`.

Type the following code.

```python
print("Hello, World!")
```

## Run Using the Terminal

Open the integrated terminal.

```text
Terminal → New Terminal
```

Run:

```bash
python main.py
```

or

```bash
python3 main.py
```

Expected output

```text
Hello, World!
```

Congratulations!

You have successfully written and executed your first Python program.
