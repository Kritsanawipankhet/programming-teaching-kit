# Pre-course Skill Check

This short assessment helps you understand your current programming knowledge before starting the course.

There is **no passing score**.

The purpose is to identify your strengths and determine which lessons you should focus on.

## Instructions

- Answer all questions without searching for answers.
- Choose the best answer for each question.
- Record your score at the end.
